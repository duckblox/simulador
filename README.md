# 🚀 Cockpit Galáctico — Edição Aprendiz

> **Mire, atire, decole e explore.**

## ▶️ [**JOGAR AGORA → duckblox.github.io/simulador**](https://github.io)

*Abra o link no navegador do celular, tablet ou computador. Não precisa instalar nada, baixar nada nem criar conta.*

---

Um simulador interativo para brincar de aprender: assuma o controle de uma nave espacial, interaja com os comandos do painel, prepare os sistemas e descubra, na prática, como coordenar ações para realizar uma decolagem espacial bem-sucedida.

## 🎮 Como jogar
1. **Mire com o mouse:** Movimente o cursor pela tela para direcionar a mira e explorar o espaço ao redor.
2. **Clique para atirar:** Use o botão esquerdo para disparar os lasers da nave contra os alvos.
3. **Interaja com o painel:** Clique e arraste a alavanca e os botões do painel de controle para configurar os sistemas de voo.
4. **Decolar:** Ative o comando de decolagem assim que o painel estiver pronto para iniciar a jornada galáctica!

## 💡 O que se aprende jogando
- **Coordenação motora e reflexo:** Controle de mira precisa e tempo de reação ao acionar os comandos.
- **Lógica e sequenciamento:** Compreensão de causa e efeito ao interagir com alavancas e botões analógicos.
- **Exploração espacial lúdica:** Estímulo à imaginação, à curiosidade científica e ao interesse por tecnologia e astronomia.

## 📱 Dica: atalho na tela inicial
No celular ou tablet, abra o jogo no navegador e use a opção **"Adicionar à tela inicial"** do menu. Ele passa a abrir como um aplicativo, com apenas um toque.

## ⚠️ Avisos
**Para quem joga:** Esta é uma simulação para diversão e aprendizado. Lembre-se de fazer pausas, piscar os olhos, beber água e brincar também longe das telas.

**Para responsáveis:**
- Não há coleta de dados pessoais, cadastro, compras com dinheiro real nem anúncios de terceiros.
- O jogo roda inteiramente no navegador do aparelho, garantindo um ambiente seguro e isolado para as crianças.
- O objetivo principal é ilustrar ideias de causa, efeito e interatividade digital de forma simples e visual.
- Recomendamos combinar um tempo saudável de tela e conversar com a criança sobre o que cada botão e alavanca faz no comando da nave.

## 🔍 Curiosidade
O simulador é feito de forma leve em HTML, CSS e JavaScript. Quem tiver curiosidade de ver os bastidores e entender como os botões e interações foram programados pode ler o código direto no arquivo deste repositório.
